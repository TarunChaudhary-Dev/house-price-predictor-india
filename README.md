# 🏠 House Price Predictor — India

My first ML model built from scratch using 
NumPy and Pandas — no ML libraries used!

## 📌 About
Predicts house prices in Gurgaon, India based 
on area, bedrooms, and bathrooms using 
Multiple Linear Regression with Gradient Descent.

## 🧠 What I Built
- Implemented Gradient Descent manually
- Used real India housing dataset (964 houses)
- Applied Feature Scaling for better training
- Multiple Linear Regression from scratch

## 🛠️ Tech Stack
- Python
- NumPy
- Pandas

## 📊 Dataset
- Source: Kaggle — House Price Prediction India
- Size: 964 houses (Gurgaon, Haryana)
- Features: Area, Bedrooms, Bathrooms, Price

## 🚀 How to Run
pip install numpy pandas
python real_model.py

## 📈 Model Details
- Algorithm: Multiple Linear Regression
- Training: Gradient Descent (1000 iterations)
- Features: Area (sqft), Bedrooms, Bathrooms
- Target: Price (Crores)
